How the rules work

  • The most urgent matching condition sets the priority.
  • Separate keywords with commas. Plurals and -ing or -ed endings match automatically.
  • severe+stomach pain needs both parts in the same sentence.
  • dehydrat* matches any word that starts with it.
  • Words after no, not, without or denies are ignored, so "no chest pain" doesn't match.
  • Rank 0 rows are red flags and always Critical. A lower rank is seen sooner within the same priority.

Connection to the AI model

Use the Qwen model on your laptop

  • On the laptop, run laptop\enable-ollama-lan.ps1 once. It lets Ollama accept connections from the Pi.
  • Connect the laptop and the Pi to the same network, then press Find on network.
  • No laptop? Install Ollama on the Pi, pull qwen3:1.7b and use http://localhost:11434.
  • The AI only ever raises a priority. The built-in rules keep working when it's offline.
